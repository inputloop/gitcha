# gitcha (Claude extension + CLI)

Zero-dependency client for a [Gitcha](https://github.com/inputloop/gitcha) registry:

- `bin/gitcha.js`: the `gitcha` CLI (first-run `gitcha login` with password + authenticator code)
- `bin/gitcha-mcp.js`: the MCP server used by the Claude Code plugin and the Claude Desktop extension

See the [main README](../README.md#installing-the-claude-extension) for installation and the
[security model](../SECURITY.md).
